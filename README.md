## 📸 Key Features & Tools

### 1. 🎨 Single Mode (Channel Packer)
* **Channel Assignment:** Map single grayscale or color images directly into **Red (R)**, **Green (G)**, **Blue (B)**, and **Alpha (A)** channels.
* **Channel Inversion:** Invert individual input channels on-the-fly (useful for converting Roughness to Smoothness/Glossiness).
* **Custom Color Fill:** Set default fallback fill values (0-255 sliders with real-time swatch preview) for missing or unassigned channels (e.g., set unassigned Alpha to 255 for opaque).
* **Live Interactive Canvas:** View combined RGBA texture in real-time with zoom and pan controls.
* **Export Options:** Download results in PNG, WebP, or JPG formats, or copy packed textures directly to the system clipboard.

### 2. 📦 Bulk Batch Mode
* **Multi-Set Processing:** Batch pack dozens or hundreds of texture sets in parallel.
* **Suffix Auto-Matching:** Automatically assigns channel textures based on filename suffixes (e.g., `_roughness`, `_metallic`, `_ao`, `_alpha`).
* **Batch Drag & Drop:** Drag entire folders or image groups into the workspace.
* **Bulk Export:** Preview individual sets, export single PNGs, or download a full `.zip` archive containing all packed texture sets (`JSZip`).

### 3. 🔄 Normal Map Converter
* **DirectX ↔ OpenGL Format Conversion:** Instantly convert between **DirectX (Y-)** and **OpenGL (Y+)** normal map standards by flipping the Green channel.
* **Channel Inversion & Normalization:** Invert R, G, or B channels independently and normalize normal vectors.
* **Reconstruct Z (Blue) Channel:** Reconstruct missing or compressed normal Z channels using the mathematical formula $\sqrt{1 - X^2 - Y^2}$ (ideal for BC5 / RG normal map compression formats).

### 4. ⛰️ Height-to-Normal Generator
* **Gradient Operators:** Convert grayscale heightmaps / displacement maps into tangent-space normal maps using **Sobel**, **Prewitt**, or **Scharr** edge-detection filters.
* **Intensity Control:** Fine-tune height strength multiplier from 0.1x to 20x.
* **Invert Height Option:** Flip elevation direction before normal calculation.

### 5. ✂️ Channel Splitter (Decomposer)
* **Decompose Packed Maps:** Upload any packed RGBA or RGB composite texture image.
* **Channel Extraction:** Instantly split into 4 separate grayscale image files for Red, Green, Blue, and Alpha channels.
* **Export Flexibility:** Download individual channels or export all extracted channels at once as a `.zip` bundle.

### 6. 📚 Info & Engine Standards Cheat Sheet
Built-in reference guide for popular engine and material standards:
* **Unreal Engine 4/5 (ORM):** `R` = Ambient Occlusion, `G` = Roughness, `B` = Metallic
* **Unity Standard Shader:** `RGB` = Metallic/Albedo, `A` = Smoothness
* **Godot 4 Standard Material:** `R` = Ambient Occlusion, `G` = Roughness, `B` = Metallic
* **Blender / glTF 2.0:** `R` = Occlusion, `G` = Roughness, `B` = Metallic
* **CryEngine / Lumberyard:** `A` = Smoothness
